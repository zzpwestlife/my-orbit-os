# 心智模型

## 定义

心智模型（Mental Model）是指人在大脑中构建的关于某个系统、概念或问题的内部表征。它是我们理解和预测事物运作方式的认知框架，帮助我们在复杂情境中做出决策和解决问题。

## 要点

- **内部表征**：在大脑中构建的关于外部世界的模型
- **认知框架**：用于理解、推理和预测的思维结构
- **动态构建**：需要时间和认知资源来建立和维护
- **易碎性**：容易被打断或干扰而崩塌
- **重建成本高**：一旦崩塌，重新构建需要大量时间和精力

## 示例

### 编程中的心智模型

当开发一个功能模块时，程序员需要在脑中构建：

**系统层面**：
- 模块的职责和边界
- 与其他模块的交互界面
- 数据如何在系统中流转

**实现层面**：
- 当前的架构设计
- 可能的边界情况
- 潜在的性能瓶颈

**质量层面**：
- 需要处理的异常情况
- 测试覆盖的场景
- 代码的可维护性

这些信息交织在一起，形成一个复杂的认知网络，支撑着程序员做出正确的决策。

### 心智模型的脆弱性

**场景**：你正在深入开发一个复杂的认证模块

**被打断前**：
- 清楚地知道每个函数的作用
- 理解数据流转的每个环节
- 记得需要处理的 5 个边界情况
- 正在思考第 3 个边界情况的最佳解决方案

**被打断后**（如：回复一个消息，处理另一个任务）：
- 回来时需要重新阅读代码
- 重新理解数据流转
- 重新回忆那 5 个边界情况是什么
- 重新思考为什么选择当前的实现方式

**重建时间**：15-30 分钟甚至更长

### 心智模型与上下文切换

**单任务工作**：
```
构建心智模型 → 深入工作 → 完成任务
```

**频繁切换**：
```
构建模型 A → 工作 5 分钟 → 切换
构建模型 B → 工作 5 分钟 → 切换
构建模型 C → 工作 5 分钟 → 切换
回到 A → 重新构建模型 A → 工作 5 分钟 → ...
```

大量时间浪费在重复构建心智模型上，而非真正的工作。
