# 隐性知识与显性知识

## 定义

隐性知识（Tacit Knowledge）是存在于个人头脑中、难以用语言表达的知识，如经验、直觉、技能。显性知识（Explicit Knowledge）是可以用文字、图表、公式等明确表达和传播的知识。

## 要点

- **隐性知识特征**：难以表达、高度个人化、依赖情境、通过实践获得
- **显性知识特征**：可编码、易传播、可存储、可复制
- **知识转化**：组织的核心能力是将隐性知识转化为显性知识
- **知识螺旋**：隐性↔显性的持续转化推动组织学习

## 示例

**隐性知识的例子**：
- 资深销售如何判断客户的购买意向
- 老师傅如何凭手感判断机器是否正常
- 优秀程序员如何设计系统架构
- 交易员如何在压力下保持纪律

**显性知识的例子**：
- 销售话术手册
- 机器操作规程
- 代码规范文档
- 交易系统的入场和出场规则

**知识转化的四种模式**（野中郁次郎）：

1. **社会化**（隐性→隐性）：师徒制，观察学习
2. **外化**（隐性→显性）：将经验写成文档
3. **组合**（显性→显性）：整合不同的文档形成新知识
4. **内化**（显性→隐性）：通过学习文档形成个人能力

**在 AI 时代的意义**：

Claude Skills 的核心价值就是将隐性知识显性化：
- 专家大脑中的经验 → 可执行的 Skill
- 对话中的临时知识 → 可版本化的资产
- 个人的专业能力 → 组织的共享资源
