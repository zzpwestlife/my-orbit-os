# 瑞士奶酪模型

## 定义

瑞士奶酪模型（Swiss Cheese Model）是一种风险管理和系统安全理论，由 James Reason 提出。该模型认为，没有单一的防护层能够完全防止事故，但通过堆叠多个不完美的防护层，可以大幅降低风险，因为各层的"漏洞"不太可能同时对齐。

## 要点

- **多层防护**：每一层都是不完美的，都有"漏洞"
- **漏洞不对齐**：通过堆叠多层，降低所有漏洞同时对齐的概率
- **纵深防御**：不依赖单一防护措施，而是建立多重保障
- **适用广泛**：从医疗安全到软件工程都可应用
- **AI 时代应用**：在 AI 生成代码的场景中，通过多层验证建立信任

## 示例

### 传统应用：航空安全

```
第1层：飞行员培训
第2层：飞行前检查清单
第3层：自动驾驶系统
第4层：空中交通管制
第5层：紧急程序
```

即使某一层失效，其他层仍能提供保护。

### AI 编程中的应用

在 AI 生成代码的场景中，建立多层验证机制：

**Layer 1: 比较多个选项**
- 让 3 个 Agent 用不同方式实现
- 选择通过最多验证的方案
- 漏洞：可能所有方案都有相同的盲点

**Layer 2: 确定性护栏**
- 编码规范（linter）
- 类型检查
- 单元测试
- 漏洞：测试可能不完整

**Layer 3: 人类定义验收标准**
- BDD 规格
- 业务逻辑验证
- 边界情况检查
- 漏洞：人类可能遗漏某些场景

**Layer 4: 权限系统**
- 限制 Agent 的文件访问范围
- 敏感操作需要人工批准
- 漏洞：权限配置可能不当

**Layer 5: 对抗性验证**
- 独立的验证 Agent
- 红队 Agent 尝试破坏实现
- 漏洞：对抗 Agent 可能不够聪明

### 可视化

```
[Layer 1: 🧀] ← 有漏洞
[Layer 2: 🧀] ← 有漏洞（不同位置）
[Layer 3: 🧀] ← 有漏洞（不同位置）
[Layer 4: 🧀] ← 有漏洞（不同位置）
[Layer 5: 🧀] ← 有漏洞（不同位置）

风险只有在所有漏洞对齐时才会穿透 ↓
```

### 实际效果

单层防护失效率：20%
五层独立防护同时失效率：0.2^5 = 0.032%

通过堆叠不完美的过滤器，将风险降低到可接受的水平。
