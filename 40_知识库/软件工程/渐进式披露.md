# 渐进式披露

## 定义

渐进式披露（Progressive Disclosure）是一种信息架构和交互设计原则，指根据用户的需求逐步展示信息，而非一次性呈现所有内容。在 AI 系统中，它指根据任务需要分层加载上下文，避免挤爆模型的上下文窗口。

## 要点

- **分层加载**：信息按需求的紧迫性分层组织
- **降低认知负担**：用户/系统只看到当前需要的信息
- **可扩展性**：允许信息库无限扩展而不影响性能
- **上下文优化**：在 AI 系统中，有效管理有限的上下文窗口

## 示例

**在 Claude Skills 中的应用**：

**第一层（元数据）**：
```
- 财务报表生成
- 法律文档审核
- 客户数据分析
```

**第二层（触发后加载）**：
```
技能：财务报表生成
步骤：
1. 连接数据库
2. 执行查询
3. 数据校验
4. 生成报表
```

**第三层（需要时加载）**：
```
详细的 SQL 查询语句
数据校验规则
报表模板格式
```

**传统 UI 设计中的应用**：
- 表单：先显示必填项，点击"高级选项"后显示可选项
- 菜单：主菜单显示常用功能，子菜单显示详细选项
- 文档：目录 → 章节 → 详细内容

**优势**：
- 上下文窗口不会被无关信息占满
- 技能库可以包含成百上千个技能
- 只有被触发的技能才会加载详细指令
