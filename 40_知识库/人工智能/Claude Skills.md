# Claude Skills

## 定义

Claude Skills 是 Anthropic 提出的一种 AI 架构模式，将专业经验打包成可复用的、可组合的技能模块，而非为每个任务创建独立的 Agent。Skill 是把组织经验从对话里的隐性知识，变成可版本化、可测试、可执行的显性资产。

## 要点

- **流程性知识**：强调"怎么做"而非"是什么"，包含具体的执行步骤
- **可组合性**：像乐高积木一样，可以叠加不同的技能形成复杂能力
- **可执行性**：将确定性任务交给脚本，模型只负责规划和解释
- **资产化**：技能成为企业的显性资产，可以版本管理、复用和迭代

## 示例

**Skill 的物理结构（三件套）**：

1. **元信息（Skill.md）**
   - 名字：`财务报表生成`
   - 描述：`从数据库拉取财务数据，校验并生成标准报表`
   - 用于预加载，让 Agent 知道自己有哪些技能

2. **执行指南**
   - 步骤1：连接财务数据库
   - 步骤2：执行 SQL 查询拉取数据
   - 步骤3：调用校验脚本检查数据完整性
   - 步骤4：使用模板生成报表

3. **配套资源**
   - `validate.py`：数据校验脚本
   - `template.xlsx`：报表模板
   - `queries.sql`：标准查询语句

**对比传统 Agent**：
- ❌ 传统：创建"财务 Agent"、"法务 Agent"、"HR Agent"
- ✅ Skills：一个通用 Agent + 财务 Skill + 法务 Skill + HR Skill
