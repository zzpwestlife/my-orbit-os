# Vibe Coding

## 定义

Vibe Coding 是用自然语言指挥 AI 生成代码、以沉浸体验和创造感受为核心驱动力的编程方式。与其说是一种技术范式，不如说是 **AI 时代的创造者体验**。

## 要点

- **本质**：不是为了产出可维护的生产代码，而是为了获得"我说了算"的创造快感
- **钓鱼隐喻**：对很多中年人来说，Vibe Coding 就像钓鱼——提供了一个合法的独处理由和自我主宰的体验空间
- **门槛崩溃**：AI 把"从想法到运行"的门槛踩到地板，二十年前需要苦学的技能变成了描述清楚就能执行
- **过程 > 结果**：那个小工具第二天可能你自己都不会再打开，但过程里"我能做出点什么"的感觉是真实的

## 为何对中年人尤其珍贵

> 凌晨时分在社交媒体上最兴奋地晒出 AI 小产品的，往往不是 00 后程序员，而是三四十岁的中年人。他们分享的不是技术，而是失而复得的感动——"我居然还能做出点什么来。"

中年人最缺乏"自我主宰"体验（角色叠加、时间被碎片化）。Vibe Coding 提供了一段名正言顺的"属于自己的时间"。
