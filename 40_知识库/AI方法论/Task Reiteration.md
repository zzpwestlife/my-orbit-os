# Task Reiteration

## 定义

Task Reiteration（任务重申）是在 AI Agent 执行长任务期间，**持续将关键信息推送到上下文末尾**的机制，以对抗 LLM 注意力的位置偏差。

本质不是"记录进度"，而是**持续刷新模型的注意力焦点**。

## 要点

- LLM 对上下文中间的信息注意力最弱，开头（System Prompt）和末尾（最新内容）注意力最强
- To-Do List 真正的价值不在于"列出步骤"，而在于每步完成后把"下一步"重新放到上下文末尾
- 静态放在开头的 To-Do List = 无效（很快被淹没在中间区域）
- 不仅要重申"下一步是什么"，还要重申"当前适用的规则/约束/Skill"

## 两类信息处理

| 信息类型 | 处理方式 | 原因 |
|----------|----------|------|
| 静态规则（全局通用） | 放入 System Prompt | 始终可见；修改 System Prompt 代价高，保持稳定 |
| 动态信息（进度/Skill/计划） | 每步追加到上下文末尾 | 保持在注意力高地；避免破坏 KV 缓存 |

## 示例

```
[执行第 45 步后，追加到上下文末尾]

当前进度：已完成 1-45 步
下一步：第 46 步 - 生成场景 B 的过渡动画
当前规则提醒：
- 每段代码必须独立完整，不得复用前段框架
- 输出长度不少于 80 行
- 颜色方案必须与场景 A 形成对比
```
