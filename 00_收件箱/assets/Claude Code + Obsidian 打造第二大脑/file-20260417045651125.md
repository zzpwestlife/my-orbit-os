# 工具安装问题排查与解决文档

> 创建时间：2026-04-17
> 环境：macOS Darwin，zsh

## 一、问题概述

需要安装三个工具：
1. `npx skills add alchaincyf/darwin-skill` - CodeBuddy skill
2. `npm install -g codeburn` - AI token 消耗追踪工具
3. `curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash` - Hermes Agent

## 二、问题原因分析

### 1. codeburn 安装失败 - 网络问题

**症状**：
```
npm install -g codeburn
# 超时等待，无响应
```

**原因**：
- npm 默认使用官方源 `https://registry.npmjs.org/`
- 测试发现 `npm ping` 连接失败（网络不可达）
- 官方源在中国大陆访问极慢或完全不可达

**解决方案**：
切换 npm 镜像源到国内淘宝镜像：
```bash
npm config set registry https://registry.npmmirror.com
npm install -g codeburn
```

### 2. darwin-skill 和 hermes-agent 安装失败 - GitHub 访问问题

**症状**：
```bash
curl -fsSL https://raw.githubusercontent.com/... # 超时
git clone https://github.com/... # 超时
```

**原因**：
- 网络无法直接访问 `github.com`、`raw.githubusercontent.com`
- `curl` 测试连接超时（约 60-75 秒）
- GitHub 镜像站（ghproxy.cn 等）也无法访问

**排查过程**：
```bash
# 测试网络连接
curl -I https://github.com  # 超时

# 检查代理配置
scutil --proxy
# 发现系统未配置代理

# 检查运行的代理软件
ps aux | grep -iE "vpn|proxy|clash"
# 发现 Clash Verge 在运行，监听端口 7897
```

**解决方案**：
配置 Git 使用 Clash Verge 代理：
```bash
# 手动配置 Git 代理
git config --global http.proxy http://127.0.0.1:7897
git config --global https.proxy http://127.0.0.1:7897

# 验证代理生效
curl -I https://github.com
# HTTP/1.1 200 Connection established
```

## 三、过程中的坑

### 坑 1：npm 默认源访问慢
- **现象**：npm install 命令看似在执行但永远不返回
- **排查**：使用 `npm ping` 测试连接速度
- **教训**：在中国使用 npm 前先检查/切换镜像源

### 坑 2：代理软件在运行但未配置到系统
- **现象**：Clash Verge 已启动并正常工作（浏览器能访问外网），但命令行工具无法访问 GitHub
- **原因**：代理软件是"全局模式"或"PAC 模式"，仅对系统应用生效，命令行工具默认不走代理
- **教训**：代理软件运行 ≠ 命令行可用代理，需要手动配置

### 坑 3：npm 超时但不报错
- **现象**：`npm install` 命令静默等待，无超时提示
- **教训**：长时间无输出应该怀疑网络问题，而不是程序卡死

### 坑 4：Git clone 超时需要手动清理
- **现象**：克隆失败后残留部分目录
- **教训**：重试前需要清理：
```bash
rm -rf ~/.hermes/hermes-agent
```

### 坑 5：GitHub 镜像不稳定
- **现象**：尝试多个 GitHub 镜像（ghproxy.cn、fastgit.xyz 等）全部失败
- **教训**：最终还是要配置代理访问原始 GitHub

## 四、最终安装步骤

### 1. codeburn
```bash
# 切换 npm 镜像
npm config set registry https://registry.npmmirror.com

# 安装
npm install -g codeburn

# 验证
codeburn --version
```

### 2. darwin-skill
```bash
# 配置 Git 代理
git config --global http.proxy http://127.0.0.1:7897
git config --global https.proxy http://127.0.0.1:7897

# 克隆到 CodeBuddy skills 目录
git clone https://github.com/alchaincyf/darwin-skill.git ~/.codebuddy/skills/darwin-skill
```

### 3. hermes-agent
```bash
# 配置 Git 代理（如未配置）
git config --global http.proxy http://127.0.0.1:7897
git config --global https.proxy http://127.0.0.1:7897

# 克隆仓库
git clone https://github.com/NousResearch/hermes-agent.git ~/.hermes/hermes-agent

# 创建虚拟环境
cd ~/.hermes/hermes-agent
uv venv .venv

# 安装依赖
source .venv/bin/activate
uv pip install -e .

# 创建命令软链接
ln -sf ~/.hermes/hermes-agent/.venv/bin/hermes ~/.local/bin/hermes
```

## 五、关键命令参考

### 网络诊断
```bash
# 测试 npm 源
npm ping

# 测试 GitHub 连接
curl -I https://github.com

# 检查系统代理
scutil --proxy

# 检查代理软件进程
ps aux | grep -iE "clash|surge|v2ray|shadowsocks"
```

### Git 代理配置
```bash
# 设置代理
git config --global http.proxy http://127.0.0.1:7897
git config --global https.proxy http://127.0.0.1:7897

# 取消代理
git config --global --unset http.proxy
git config --global --unset https.proxy

# 查看当前配置
git config --global --list | grep proxy
```

### npm 镜像切换
```bash
# 切换到淘宝镜像
npm config set registry https://registry.npmmirror.com

# 切回官方源
npm config set registry https://registry.npmjs.org/

# 查看当前源
npm config get registry
```

## 六、注意事项

1. **代理端口**：Clash Verge 默认端口是 `7897`，其他代理软件端口可能不同
2. **代理生效范围**：Git/npm/curl 等工具需要单独配置代理，系统代理设置不影响它们
3. **代理软件状态**：确保代理软件在运行，否则配置了代理也无法联网
4. **PATH 优先级**：软链接路径需要在 PATH 中才能直接调用命令
