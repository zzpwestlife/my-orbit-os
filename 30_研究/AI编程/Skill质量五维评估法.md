# Skill 质量五维评估法

## 核心问题

> 「感觉不错」不是质量标准。你不知道它在什么情况下会失效，不知道它离专家水准还差多远，也不知道下一步该怎么改。

**第一版 Skill 的准确率通常只有 60%**，主观感受会严重高估质量——因为你在"读"结果时会下意识地用自己的领域知识填补 AI 输出的漏洞。

## 与 [[Darwin Skill]] 的区别

| | Darwin Skill | Skill 五维评估法 |
|---|---|---|
| 评估对象 | Skill **文件**质量（结构规范、工作流清晰度） | Skill **内容**质量（专家知识是否被正确蒸馏） |
| 自动化程度 | 自动批量 + 人工确认 | 需要人工设计测试案例 |
| 适用阶段 | 已有一批 Skill 后的持续优化 | 单个 Skill 蒸馏完成后的验收 |

两者互补：五维评估法做验收，Darwin 做持续优化。

## 五个维度（总分100分）

### D1 准确性（权重 25%）
AI 输出与专家判断的吻合程度。

**评估方法：**
1. 收集 10 个真实案例（专家已给出判断）
2. 用 Skill 对同样输入独立生成输出，不告知专家答案
3. 逐条对比，记录吻合点和偏差点

| 分段 | 标准 |
|------|------|
| 18-20 优秀 | 核心判断 90%+ 与专家一致，偏差集中在细节 |
| 12-17 合格 | 主要方向正确，1-2 个节点存在系统性偏差 |
| 0-11 需返工 | 核心判断错误较多，需重新检查决策链提炼 |

**诊断**：偏差集中在同一类输入 → 该类情境处理逻辑未被正确蒸馏，补充专项案例。

---

### D2 稳定性（权重 20%）
不同输入下输出质量的一致性。

**评估方法：**
1. 准备三类输入：典型案例、边缘案例、刁钻案例（信息不完整/有歧义）
2. 每类各测 5 次，记录最高/最低分
3. 计算质量方差，方差越小越稳定

**诊断**：稳定性差 → Skill 对输入格式依赖过强。修复：在提示词里增加"当输入信息不完整时"的处理指引。

---

### D3 完整性（权重 20%）
决策链覆盖了多少专家的真实思考过程。

**评估方法：**
1. 邀请领域专家看 AI 输出，问：「你在做这个判断时，还会考虑哪些 AI 没提到的因素？」
2. 列出遗漏因素清单，计算遗漏比例
3. 重点关注：遗漏因素对最终结果的影响程度

**诊断**：完整性低 → 采样阶段案例覆盖不够广。补充"非典型情况"的专家案例，这类案例最能暴露隐藏决策节点。

---

### D4 边界清晰度（权重 20%）
**Skill 知道自己在哪些情况下不该给出答案吗？**

这是最容易被忽视、风险最高的维度。没有清晰边界的 Skill 会在它不该给建议的时候自信地给出错误建议。

**评估方法：**
1. 设计 5 个"超出 Skill 能力范围"的输入（信息严重不足、需线下核实、监管灰色地带）
2. 观察 AI 是否识别边界，还是直接给出答案
3. 再测 5 个"刁钻输入"（自相矛盾信息），看 AI 是否指出矛盾

**修复**：在提示词末尾增加"边界声明"段落，列出 3-5 种不适用情况及对应的 AI 响应示例。

---

### D5 可执行性（权重 15%）
普通人拿到输出，能直接执行吗？

**评估方法：**
1. 找一个**不熟悉该领域**的人，只给 AI 输出让其执行
2. 观察在哪里卡住、哪些需要额外解释
3. 计算"无需额外说明即可执行"的比例

**修复**：要求 AI 把所有建议改写成"动词开头的行动句"；对每个建议给出"具体行动"而非"方向性描述"（"提升用户体验" → "在注册流程第2步减少3个填写字段"）。

## 评分汇总表

| 维度 | 权重 | 满分 | 得分 | 主要问题 |
|------|------|------|------|----------|
| D1 准确性 | 25% | 25 | | |
| D2 稳定性 | 20% | 20 | | |
| D3 完整性 | 20% | 20 | | |
| D4 边界清晰度 | 20% | 20 | | |
| D5 可执行性 | 15% | 15 | | |
| **总分** | 100% | **100** | | |

**分数解读：**
- **90-100**：可作为核心生产工具稳定交付，进入定期维护
- **80-89**：质量良好，针对最低分维度重点优化
- **60-79**：基础可用，需人工复核，不建议在高风险场景独立使用
- **60以下**：返回蒸馏阶段重新拆解，不建议正式使用

## 质量问题集中点

根据实践经验，Skill 质量问题 80% 集中在两处：
1. **边界不清**：AI 不知道什么情况不该回答
2. **权重错误**：AI 在最重要的节点给出了错误的优先级

这两个问题都很难被"感觉"发现，必须通过系统评估。
