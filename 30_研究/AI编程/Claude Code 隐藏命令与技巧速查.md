# Claude Code 隐藏命令与技巧速查

## 核心命令

### 1. /btw — 无污染插问

**用途**：在 Claude 正在干活时插入问题，**不会被加入对话历史**，避免上下文污染。

- 几乎不费 token（复用当前的提示缓存）
- 回答完按空格/回车直接消除
- 两个进程纯粹并行状态

**使用场景**：执行长任务时突然想问个不相关的问题。

### 2. /rewind — 代码与对话分别回退

**用途**：撤销/回退，类似 Ctrl + Z。

**2 月升级**：代码和对话可以**分别回退**。

选项：
- 回退代码和对话
- 回退对话但保留代码
- 回退代码但保留对话
- 将从该点开始的对话压缩释放上下文窗口空间

**使用场景**：试验新方案，不行的话代码回退、对话留着，Claude 还记得刚才聊了什么。

### 3. /insights — AI 反向观察你

**用途**：生成 HTML 报告，分析过去一个月使用习惯。

包含：
- 最常用哪些命令
- 重复性操作模式
- 推荐自定义命令和 Skills
- 翻车现场分析

**建议**：每个月跑一次。

### 4. /model opusplan — Pro 用户福音

**用途**：自动在需要复杂推理时使用 Claude Opus 4.6（plan 模式），然后切换到 Claude Sonnet 4.6 执行。

**隐藏命令**：直接 `/model` 切换模型看不到这个模式。

**适用人群**：20 刀 Pro 订阅用户（Opus 额度有限）。

### 5. /simplify — 三合一代码审查

**用途**：同时启动三个平行 Agent，分别从**代码复用、代码质量、运行效率**三个角度审查改动。

**建议**：每次写了几个大功能更新后顺手跑一遍。

### 6. /branch — 平行宇宙

**用途**：把当前对话分叉出新会话，原会话不受影响。

**与 /rewind 的区别**：
- /rewind 是后悔药（回退）
- /branch 是平行宇宙（分叉）

**使用场景**：想试两种不同实现方式，最后挑效果好的。

### 7. /loop — 定时重复执行

**用途**：让 Claude 定时重复执行某个任务。

**用法**：`/loop 5m 检查一下部署状态`（默认间隔 10 分钟）

**注意**：定期任务在创建 3 天后自动过期。桌面版可以一直运行。

### 8. /remote-control — 手机遥控

**用途**：生成 URL，手机打开后可远程操作 Claude Code。

**特点**：
- 完全同步（手机和终端）
- 代码始终在电脑上跑
- 手机只是遥控器

**命令**：`/rc` 或 `/remote-control`

### 9. /export — 导出对话

**用途**：将当前对话导出成 Markdown 文件。

**使用场景**：
- 保存有价值的架构讨论
- 作为未来的详细 context
- 导出给其他 AI（如 Codex）协同

### 10. 快捷键

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| **Ctrl + V** | 直接粘贴截图 | Mac 也是 Ctrl + V（不是 Cmd + V） |
| **Ctrl + J** / **Option + 回车** | 换行 | Mac 两种方式都可以 |
| **Ctrl + R** | 搜索 prompt 历史 | 搜索之前输入过的所有 prompt |
| **Ctrl + U** | 删除整行输入 | 快速清空当前输入 |
| **Esc Esc** | 回退 | 等同于 /rewind |
