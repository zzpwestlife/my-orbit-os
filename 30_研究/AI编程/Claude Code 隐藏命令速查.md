# Claude Code 隐藏命令速查

## 十大实用命令

### 1. `/btw` — 并行提问不污染上下文
在 Claude 正在干活时插入一个问题，**不加入对话历史**。回答完按空格/回车消除，零上下文污染，几乎不费 token（复用当前提示缓存）。

### 2. `/rewind` — 代码和对话分别回退
按两下 Esc 或打 `/rewind`，可选择：
- 回退代码和对话
- 回退对话但保留代码
- 回退代码但保留对话
- 从该点开始压缩对话释放窗口

> 适合做实验：代码回退 + 对话留着 → Claude 知道这条路不通，换方向不用重新解释

### 3. `/insights` — 使用习惯分析
生成 HTML 报告，分析过去一个月的使用习惯：最常用命令、重复性操作模式，推荐自定义命令和 Skills。建议每月跑一次。

### 4. `/model opusplan` — 混合模型策略（隐藏命令）
复杂推理时自动用 Opus 做规划，然后切换到 Sonnet 执行。**Pro 用户福音**——规划用 Opus 保质量，写代码用 Sonnet 省额度。

### 5. `/simplify` — 三合一代码审查
同时启动三个并行 Agent，分别从**代码复用、代码质量、运行效率**三个角度审查改动。比 `/review` 更好用。

### 6. `/branch`（原 `/fork`）— 分叉会话
把当前对话分叉出一个新会话，原会话不受影响。与 `/rewind` 的区别：一个是后悔药，一个是平行宇宙。

### 7. `/loop` — 定时任务
`/loop 5m 检查部署状态` → 每 5 分钟执行一次（默认 10 分钟）。结果在对话上下文里，Claude 可基于结果做后续操作。3 天后自动过期。

### 8. `/remote-control`（`/rc`）— 手机遥控
生成 URL，用手机打开后完全同步操作 Claude Code 会话。代码在电脑运行，手机只是遥控器，安全且方便。

### 9. `/export` — 导出对话为 Markdown
将整段对话导出为 Markdown 文件，保存架构讨论、决策过程等有价值的上下文。

### 10. 实用快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + V` | 直接粘贴截图（Mac 注意是 Ctrl 不是 Cmd） |
| `Ctrl + J` / `Option + 回车` | 换行 |
| `Ctrl + R` | 搜索历史 prompt |
| `Ctrl + U` | 删除整行输入 |
| `Esc Esc` | 回退（= `/rewind`） |
