# 横纵分析法 — 两条轴的研究框架

## 核心思想

> 这个时代做研究，真正稀缺的不再是信息，而是你对这个世界**有多好奇**。方法和工具都是后面的事，好奇心在前面。

[[横纵分析法]] 是一套两轴研究框架，脱胎于语言学（索绪尔的历时/共时分析）和社会科学（纵向研究/横截面研究），结合商业竞争战略分析，封装为 AI 可执行的通用框架。

## 两条轴

### 纵轴（时间维度）
沿时间线还原完整故事：
- 它怎么来的？谁做的？
- 中间经历了什么关键节点？
- 为什么在某个时间点突然爆发或掉头？

### 横轴（比较维度）
在当下时间点横向对比：
- 跟同赛道的东西有何不同？
- 用户为什么选它而不选别的？
- 它在整个赛道里处于什么位置？

### 交叉洞察（核心价值）

> 纵向告诉你它是怎么走到今天的，横向告诉你它今天站在哪。两条轴一交叉，你能看到单独看任何一条都看不到的东西。

例如：今天某个优势其实是三年前一个不起眼决策慢慢积累出来的。

```
纵轴 (时间)
    │
    │    ╳  ← 交叉洞察
    │  ╱
────┼──────── 横轴 (比较)
    │
```

## 工具支持

### Prompt 版本
适配支持深度研究的 AI：ChatGPT DeepResearch、Claude 深度研究、豆包专家模式等

使用方式：修改等式中的研究对象，直接提交。

**支持的研究对象类型（Prompt 自动调整侧重）：**
- 产品 → 重点看版本迭代和功能对比
- 公司 → 重点看融资历程和商业模式
- 技术概念 → 重点看演进脉络和同类对比
- 人物 → 重点看职业轨迹和同领域比较

实测：研究 Harness，13 分钟，约 1 万字报告，纵向历史清晰，横向与 Prompt Engineering / Context Engineering / Agent Engineering 对比专业。

### Skill 版本（hv-analysis）

来自 [[khazix-skills]] 仓库，功能更完整：
- 并行子 Agent 分三路收集信息（纵向历史、横向竞品、补充资料）
- 接入 arXiv API 查学术论文
- 自动生成结构化报告（纵向 6000-15000 字 / 横向 3000-10000 字 / 交汇洞察 1500-3000 字）
- 最终用 WeasyPrint 生成带封面的 A4 PDF

### khazix-writer（配套写作 Skill）

29.5 KB 的写作方法论手册，核心定位：**「有见识的普通人在认真聊一件打动他的事」**

五种文章原型 + 详细写作技法（长短句节奏、口语化打断、知识顺嘴带出）+ 四层自检体系（L1 硬规则 → L4 人味终审）

特别：反向约束设计，明确列出 AI 绝对不能代替人类生成的内容：编造场景、核心原创洞察、文字里的温度。

**两 Skill 串联使用：** hv-analysis 做深度研究 → khazix-writer 写成文章。

## 使用说明

```bash
# 安装（支持 Claude Code / Codex / OpenClaw）
npx skills add KKKKhazix/khazix-skills

# 触发（与 Agent 对话）
帮我研究一下 [研究对象]
```

Prompt 版本在仓库 `prompts/` 目录，可直接复制到任何有深度研究功能的 AI。

仓库地址：https://github.com/KKKKhazix/khazix-skills

## 局限

- 建立认知框架，不能替代真正深入的亲历研究
- AI 产出报告是"起点"而非"结论"，仍可能有信息不准确
- 需配合有深度研究/联网功能的工具效果才最佳
